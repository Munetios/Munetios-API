Installation

Add a captcha container and load the script. 

<div id="munetios-captcha"></div>

<script src="captcha.js"></script>

Require Verification

Prevent actions until the captcha is completed. 

<button
  verifyelementid="munetios-captcha">
  Continue
</button>

JavaScript API 

MunetiosCaptcha.isVerified(
  "munetios-captcha"
);

MunetiosCaptcha.reset(
  "munetios-captcha"
);
