Privacy-first browser protection

Munetios Web Protection

A lightweight, client-side JavaScript security layer designed to reduce exposure to malicious domains, scam infrastructure, phishing links, cryptomining scripts, and invasive third-party tracking.

Start setup See examples
0 Network requests from the protection script
Client-side Runs directly in the browser
No telemetry No analytics, cookies, fingerprinting, or tracking

Setup

Add one script tag before the closing </body> tag.

Add the protection script

Paste this into your HTML page before </body>.

<script src="https://api.munetios.com/web-protection/protection.min.js"></script>

Optional strict mode

Strict mode can block common tracking and analytics providers. Place this config before the protection script. 

<script>
  window.MunetiosProtection = {
    mode: "strict",
    warnYouTube: true
  };
</script>
<script src="https://api.munetios.com/web-protection/protection.min.js"></script>

Strict mode with YouTube warnings off

Use this when you want strict blocking but do not want YouTube embed consent warnings.

<script>
  window.MunetiosProtection = {
    mode: "strict",
    warnYouTube: false
  };
</script>
<script src="https://api.munetios.com/web-protection/protection.min.js"></script>

Key features

Designed for simple protection without remote lookups or invasive behavior.

🚫

Blocks risky domains

Helps block known malicious, scam, phishing, compromised, and cryptomining domains.

🔒

Privacy-first

No telemetry, analytics, cookies, fingerprinting, or background reporting.

⚡

Local behavior

Runs entirely in the browser using locally bundled protection rules.

🧠

Deterministic

Transparent client-side behavior without hidden server-side scoring.

🎬

Embed handling

Supports privacy-first YouTube embed handling with optional user consent warnings.

🧩

Easy setup

Drop in one script tag and configure only when your site needs stricter behavior.

Examples

Use these examples for normal websites, strict privacy setups, and attribution.

Basic HTML page

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Protected page</title>
</head>
<body>
  <h1>Protected by Munetios Web Protection</h1>

  <script src="https://api.munetios.com/web-protection/protection.min.js"></script>
</body>
</html>

Attribution example

<p>
  This site is protected by
  <a href="https://api.munetios.com/#webProtection">Munetios Web Protection</a>.
</p>
